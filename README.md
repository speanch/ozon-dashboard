# Ozon Dashboard

Streamlit-дашборд поверх Ozon Seller API и Performance API для двух кабинетов
(**Stylint** и **Room Saver**): заказы, динамика продаж, аналитика по артикулам,
рекламные кампании, бустинг и эксперименты.

## Как это работает

```
Ozon Seller API ─┐
Ozon Performance API ─┤→ ETL (run_etl.py) → SQLite (dashboard.db) → Streamlit (dashboard.py)
```

1. `run_etl.py` выгружает данные из API Ozon (заказы, остатки, финансы, цены,
   рекламная статистика, бустинг) и складывает их в локальную SQLite-базу.
2. `dashboard.py` запускает Streamlit-приложение; страницы читают только БД,
   без обращений к API.

## Страницы дашборда

| Страница | Что показывает |
|---|---|
| **Главная** | Сводка по кабинетам: заказы, принятая выручка, прибыль, остатки, рекламные метрики |
| **Динамика продаж по кабинетам** | Динамика выручки/прибыли/ДРР по дням с наложением метрик и экспериментов |
| **Динамика продаж по артикулам** | Тепловая карта продаж по артикулам за выбранный период (день/неделя/месяц/квартал/год), топ артикулов, график одного артикула с наложением метрик и экспериментов |
| **Бустинг 75%** | Товары в акции «Эластичный бустинг»: статусы, расчёт минимальных цен, что можно поднять до 75% |
| **Стратегия рекламы** | Какие кампании запускать/тестировать/отключать по статистике ROAS и ДРР, с недельными бюджетами (как в Озоне) и жёстким лимитом ДРР ≤ 15% |
| **Ценовой индекс** | Ценовые индексы товаров относительно конкурентов |
| **Эксперименты** | Справочник экспериментов (периоды, кабинеты, артикулы) — метки отображаются на графиках динамики |

## Настройка

Скопируйте `.env.example` в `.env` и заполните ключи:

- `OZON_STYLINT_API_KEY`, `OZON_RS_API_KEY` — ключи Seller API (Client-Id указаны в `.env.example`);
- `PERFORMANCE_*_CLIENT_ID`, `PERFORMANCE_*_CLIENT_SECRET` — ключи Performance API для рекламной статистики.

## Запуск

```bash
pip install -r requirements.txt

# выгрузка данных (за 60 дней по умолчанию)
python run_etl.py --days 60

# дашборд
streamlit run dashboard.py
```

## Структура

- `dashboard.py` — точка входа Streamlit, навигация по страницам
- `run_etl.py` — запуск ETL-выгрузки (`--days`, `--shops`)
- `etl/` — клиенты API (`ozon_client.py`, `performance_client.py`), pipeline, SQLAlchemy-модели, общие UI-компоненты
- `views/` — страницы дашборда
- `fetch_boost_api.py` — разовая выгрузка данных бустинга

## Конфиденциальность

- Секреты (API-ключи) читаются только из `.env`; в коде их нет, в репозиторий `.env` не попадает.
- Локальная БД (`dashboard.db`), выгрузки (`reports/`, `temp/`, `snapshots/`) не хранятся в репозитории.
